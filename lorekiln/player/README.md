# LoreKiln player (preview)

Copied from bonjohen/lorekiln-app `player/index.html` (moved there from bonjohen/LoreKiln on 2026-11-20); that repo is the source, so change it there and copy it here.

Served at https://johnboen.com/lorekiln/player/. The page holds no story content. `library.json` lists the series sites it reads (each a GitHub Pages site from a private repo, e.g. https://johnboen.com/lorekiln-roa/ from bonjohen/lorekiln-roa), each with its own `manifest.json`. `?media=https://…/` overrides that with one media folder.
